<a id="fr"></a>

## 🇫🇷 Français

**Claude_MCP.cmd** installe deux serveurs MCP pour permettre à Claude Desktop d'agir sur votre PC Windows :

- **Desktop Commander** : lire et modifier des fichiers, rechercher du contenu et exécuter des commandes PowerShell.
- **Contrôle écran** : repérer les contrôles accessibles, regarder l'écran et regrouper plusieurs actions avec un curseur visuel « Claude » indépendant de votre souris.

### Installation

1. Installez **Claude Desktop**, **Node.js 18+** et **Python 3.12+ avec tkinter**.
2. Téléchargez `Claude_MCP.cmd`, puis double-cliquez dessus. Une connexion Internet est nécessaire.
3. Une fois l'installation terminée, quittez complètement Claude Desktop, relancez-le et ouvrez une nouvelle conversation. Autorisez les outils lorsqu'ils sont proposés.

**Outils écran :** `computer_buttons`, `computer_screen`, `computer_actions`.

**Échap** arrête la séquence en cours, sans annuler les actions déjà effectuées. Les clics nécessitent des contrôles compatibles avec l'accessibilité Windows ; le clavier agit sur la fenêtre active. L'installation sauvegarde la configuration et conserve les autres MCP. Elle ne modifie pas les limites de votre compte Claude.

The installer backs up the configuration and preserves other MCP servers. It does not change your Claude account limits.

## 🇯🇵 日本語

**Claude_MCP.cmd** は、Claude Desktop から Windows PC を操作するための2つの MCP サーバーをインストールします。

- **Desktop Commander**：ファイルの読み取り・編集、内容の検索、PowerShell コマンドの実行。
- **画面操作**：アクセシビリティ対応の操作部品の検出、画面の確認、複数の操作の一括実行。自分のマウスとは独立した「Claude」という視覚的なカーソルを使用します。

### インストール

1. **Claude Desktop**、**Node.js 18 以降**、**tkinter を含む Python 3.12 以降**をインストールします。
2. `Claude_MCP.cmd` をダウンロードしてダブルクリックします。インターネット接続が必要です。
3. インストール完了後、Claude Desktop を完全に終了して再起動し、新しいチャットを開きます。確認が表示されたらツールの使用を許可します。

**画面操作ツール：** `computer_buttons`、`computer_screen`、`computer_actions`。

**Esc** キーで実行中の操作を停止できます。ただし、完了した操作は取り消されません。クリックには Windows のアクセシビリティ機能に対応した操作部品が必要です。キーボード入力はアクティブなウィンドウに送られます。インストーラーは設定をバックアップし、他の MCP サーバーを保持します。Claude アカウントの利用制限は変更されません。
